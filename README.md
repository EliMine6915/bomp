# bomp

bomp is a simple Firebase-backed todo app built with HTML, CSS and JavaScript.

The app is available at `/`, and account settings are available at `/settings`.

## Firebase setup

1. Create a Firebase project and add a Web App.
2. Enable Authentication with the Email/Password provider.
3. Enable Cloud Firestore.
4. Configure the Firebase Hosting custom domain `bomp.elimine6915.me` in the Firebase console.

## Deploy

```bash
firebase deploy
```
